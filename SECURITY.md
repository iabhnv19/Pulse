# Security Policy

## Supported Versions

We track and provide security updates for the latest stable release of Pulse.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Pulse, please report it responsibly. 

* **Do not** disclose security vulnerabilities publicly in GitHub issues.
* Instead, please report them by opening a private security advisory on the [GitHub repository](https://github.com/iabhnv19/Pulse).
* Include a detailed description of the vulnerability, steps to reproduce, and potential impact.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate the issue promptly.
